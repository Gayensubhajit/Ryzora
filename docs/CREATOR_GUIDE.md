# Ryzora Creator & Packager Guide

Welcome creators! Ryzora makes it easy to package, sign, and distribute your rices, themes, and customization assets to thousands of Linux enthusiasts.

---

## 1. Package Anatomy

Every Ryzora package is an archive or directory containing a `ryzora.json` manifest and declarative assets.

### Minimal Directory Layout:
```text
my-awesome-rice/
├── ryzora.json            # Authoritative declarative manifest
├── release.sig            # Ed25519 signature (generated by ryzora-ci)
├── preview.png            # High-resolution screenshot (16:9 recommended)
└── content/               # Declarative payload files
    ├── hyprland.conf
    ├── waybar/
    │   ├── config.jsonc
    │   └── style.css
    └── wallpapers/
        └── neon-city.png
```

## 2. Manifest Specification (`ryzora.json`)

```json
{
  "schema_version": "1.0",
  "id": "neon-cyberpunk-hyprland",
  "name": "Neon Cyberpunk Hyprland Rice",
  "version": "1.2.0",
  "author": "CyberArtist",
  "description": "A vibrant cyberpunk aesthetic featuring animated borders and glowing status bar.",
  "category": "complete_rices",
  "desktop_target": "hyprland",
  "tags": ["cyberpunk", "neon", "hyprland", "waybar", "dark"],
  "license": "MIT",
  "preview_image": "preview.png",
  "components": [
    {
      "component_type": "hyprland",
      "target_subpath": ".config/hypr/hyprland.conf",
      "source_path": "content/hyprland.conf"
    },
    {
      "component_type": "waybar",
      "target_subpath": ".config/waybar/",
      "source_path": "content/waybar/"
    },
    {
      "component_type": "wallpaper",
      "target_subpath": "Pictures/Wallpapers/neon-city.png",
      "source_path": "content/wallpapers/neon-city.png"
    }
  ],
  "requirements": {
    "desktop": ["hyprland"],
    "session": "wayland",
    "required_apps": ["hyprland", "waybar"],
    "optional_apps": ["kitty", "fastfetch"]
  }
}
```

## 3. Packaging & Signing with `ryzora-ci`

Ryzora provides the `ryzora-ci` CLI tool to validate, audit, and sign your packages.

### Step 1: Generate an Author Keypair
```bash
ryzora-ci keygen ~/.config/ryzora/my-author-key
# Creates:
#   ~/.config/ryzora/my-author-key.priv
#   ~/.config/ryzora/my-author-key.pub
```

### Step 2: Audit Your Package
Run the comprehensive pre-submission security and schema audit:
```bash
ryzora-ci audit ./my-awesome-rice/
```
The audit checks for path traversal, forbidden scripts, archive sizes, SVG active content, and valid component structures.

### Step 3: Cryptographically Sign the Package
```bash
ryzora-ci sign-package ./my-awesome-rice/ ~/.config/ryzora/my-author-key.priv \
    --author-id "cyber-artist" \
    --author-name "CyberArtist"
```
This computes the canonical tree hash across all content files and writes a valid `release.sig`.

### Step 4: Verify Your Package
```bash
ryzora-ci verify-package ./my-awesome-rice/
```

## 4. Security Rules for Package Authors

1. **NO Shell Scripts**: Do not include `.sh`, `.bash`, or script files in your package. They will fail the automated audit.
2. **Confined Targets**: All targets must map to supported components (e.g. `~/.config/hypr/`, `~/.config/waybar/`, `~/Pictures/Wallpapers/`). Never attempt to write to system or sensitive home paths.
3. **SVG Safety**: If including SVG icons or wallpapers, ensure they are pure vector graphics with zero `<script>` tags or Javascript event handlers.
